Política de privacidad

Última actualización: 23 de octubre de 2026.

Qué datos usa la app

Mi Tablero (Life OS) es una app de escritorio. Si la conectás con tu cuenta de Google, usa estos permisos de Google Calendar:

  • Ver tus calendarios y eventos, para mostrarlos en la app y avisarte antes de cada evento.
  • Crear y modificar eventos, solo cuando vos lo pedís dentro de la app.

Dónde quedan

Los datos se guardan solo en tu computadora. El acceso a Google queda cifrado con el sistema de Windows. La app no tiene servidores propios: se comunica únicamente con Google.

Con quién se comparten

Con nadie. Los datos de Google no se venden, no se usan para publicidad y no se transfieren a terceros. El uso de la información recibida de las API de Google cumple la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo borrarlos

En la app: Ajustes → Conexiones → Desconectar Google Calendar. Eso borra el acceso y los eventos guardados en tu computadora. También podés quitar el acceso desde la configuración de tu cuenta de Google.
